# AdtalosAdKit

新义互联广告 SDK 静态库。

## CocoaPods

```ruby
pod 'AdtalosAdKit', :git => 'https://github.com/adtalos/AdtalosAdKitStatic.git', :tag => '1.1.2'
```

## Swift Package Manager

在 Xcode 的 **Package Dependencies** 中添加：

```text
https://github.com/adtalos/AdtalosAdKitStatic.git
```

然后在代码中导入：

```swift
import AdtalosAdKit
```
